# anuj-barve-videos

Source for my animated lecture videos and slides, built with [Motion Canvas](https://motioncanvas.io), which turns TypeScript into video.

## What's inside

- `src/scenes/youtube/DAA/`: scenes for a Design and Analysis of Algorithms video
- `src/scenes/SMM_D1/` and `src/scenes/SMM_D2/`: Social Media Marketing lessons, with slide content stored as JSON
- `src/scenes/vid1/`: scenes for an earlier video
- `src/scenes/sandbox/`: layout, chart, code and theme experiments
- `src/scenes/components/`: shared components, such as the line chart
- `src/audio/`: narration tracks

## Run it

```bash
npm install
npm start
```

This opens the Motion Canvas editor. Choose which scenes to render in `src/project.ts`.
